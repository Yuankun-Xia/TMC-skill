# TMC Reviewer Responses

Make each concern traceable to a scientific answer, actual manuscript change, verified evidence, or outstanding author action. Accept Chinese author notes. Unless the user explicitly asks for a Chinese or other-language response letter, draft reviewer-facing prose in English and action notes in Chinese. The language of the chat alone does not change this letter-language default.

Read [response workflow and difficult cases](references/response-workflow.md). Read [TMC context](references/tmc-context.md) when a concern involves venue fit, mobile-system evidence, or claimed submission requirements.

## Build the response from the revision record

1. Identify the decision letter, reviewer comments, manuscript version and available results. Preserve reviewer IDs and comment wording. Split a multi-part concern into trackable subitems without distorting its meaning.
2. For each item record `concern | answer/action | evidence | manuscript location | status`. Use `completed`, `planned`, `needs author input`, or `respectful disagreement` as appropriate.
3. Resolve the scientific concern before polishing the response. Typical TMC concerns include unclear system relevance, unavailable observations, weak guarantees, incomparable baselines, missing overhead, unrealistic heterogeneity/mobility, and unsupported deployment or privacy claims.
4. When revision work is requested and sources are available, make the authorized edits and verify them. If only drafting is requested, work from the supplied record and mark proposed edits accurately.
5. Write the direct answer, evidence, and change/location concisely. Use past tense for completed changes only. Missing results remain author actions and cannot become "we have conducted" claims.
6. Reconcile the response, manuscript, figures, tables and numerical results in the final versions. Verify final section/figure/page/line references where available.

Never invent reviewer identities, experiments, citations, numerical values, manuscript edits, page/line locations, or editor instructions. If a locator is not verified, use an explicit author field or a known section title and identify the limitation.

## Deliverable

Lead with the requested response text or edited response file. For a full revision, include an issue/action matrix showing outstanding items and evidence dependencies. Quote each comment once in the point-by-point letter, then respond directly. Avoid repeated flattery, defensive wording, or a long generic preamble.

Do not call a response submission-ready while it contains unfilled evidence or locator fields. A carefully justified disagreement can be resolved; an unperformed experiment is still outstanding.
